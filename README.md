# loan-wise-project
CreditWise Loan System
📌 Project Overview
An end-to-end supervised machine learning pipeline designed to predict loan approval status. The project implements binary classification along with exploratory data analysis (EDA), feature engineering, and rigorous model evaluation.

🛠️ Tech Stack & Libraries
Language: Python

Data Manipulation & Analysis: Pandas, NumPy

Machine Learning Models: K-Nearest Neighbors (KNN), Logistic Regression, Naive Bayes

Evaluation Metrics: Precision, Recall, F1-Score

Environment: Jupyter Notebook

📂 Project Structure
Plaintext
MiniProject/
│
├── creditwise_dataset.csv     # Dataset containing applicant records
├── loan_wise.ipynb            # Jupyter Notebook with full ML pipeline (EDA, Training, Evaluation)
└── README.md                  # Project documentation
🚀 Key Features & Workflow
Exploratory Data Analysis (EDA): Uncovering trends and correlations in the loan applicant data.

Feature Engineering: Preprocessing and transforming raw features to optimize model performance.

Supervised Learning: Training and comparing multiple classification algorithms (KNN, Logistic Regression, Naive Bayes).

Model Evaluation: Assessing performance using critical classification metrics including Precision, Recall, and F1-Score.
